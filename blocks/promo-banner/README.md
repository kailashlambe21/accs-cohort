# Activity 2-2 — Custom commerce block (`promo-banner`)

Reference: **`modules/week-2-dropin-components/week-2.md`** (Activity 2-2).

1. Create `blocks/promo-banner/` in your storefront.
2. Copy **`promo-banner.js`** and **`promo-banner.css`** into that folder.
3. Register the block in your project’s block loader (per boilerplate — often `blocks/promo-banner/promo-banner.js` is auto-discovered).
4. Author a page table in DA.live as described in the module.
