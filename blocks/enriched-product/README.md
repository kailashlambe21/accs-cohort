# Activity 3-3 — EDS block wired to API Mesh

Reference: **`modules/week-3-app-builder/week-3.md`** (Activity 3-3).

1. Create `blocks/enriched-product/` in your storefront.
2. Copy **`enriched-product.js`** and **`enriched-product.css`** into it.
3. Set **`MESH_ENDPOINT`** in the JS file to the URL from **`aio api-mesh get`** (replace `<mesh-id>`).
4. Author the block table in DA.live per the module (SKU key).
